\begin{abstract}
Large language and vision-language models (LLMs and VLMs) can plan robot manipulation zero-shot, leveraging pretraining corpora far broader than typical robot-learning demonstrations. Their modular, gray-box nature also allows plans to be inspected before execution, unlike end-to-end vision-language-action (VLA) policies. However, a decoupled Sense-Plan-Act pipeline still requires the model to specify physical quantities such as release height, grasp width, or target position, which pretraining does not ground in the scene. We present \harness{} (\harnesslong{}), an execution harness inserted between the high-level planner and low-level skill executor. While the planner handles symbolic decisions, \harness{} recomputes action parameters from sensor measurements or committed actions. We motivate \harness{} through a structured study of LLM/VLM pick-and-place on a real UR5cb, identifying six recurring failure modes that persist even under perfect perception and therefore stem from physical reasoning rather than perception. \harness{} resolves five of the six modes for common manipulation tasks. In a 120-trial real-hardware benchmark using a unified model across both grounding modalities, the LLM implementation achieves 98.3\% task safety and success, with the remaining dominant failure being multi-object placement collision, which \harness{} does not yet resolve.
\end{abstract}
